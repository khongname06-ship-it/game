🛠️ Cài đặt Đua vịt trắc nghiệm

Trang này giúp bạn kiểm tra Firebase và tạo sẵn link cho game, không cần sửa file trên GitHub.

Bước 1. Tạo Firebase (làm 1 lần)

  1. Vào console.firebase.google.com, bấm Create a project.
  2. Build → Realtime Database → Create Database, chọn khu vực Singapore, chọn test mode.
  3. Tab Rules: xóa hết, dán luật bên dưới rồi bấm Publish.
  4. Project settings (bánh răng) → Your apps → biểu tượng </> → đăng ký app → copy khối firebaseConfig.

Bước 2. Dán cấu hình Firebase

Dán nguyên khối const firebaseConfig = { ... } (hoặc chỉ phần trong ngoặc nhọn) vào đây.

Bước 3. Link của bạn

Link CHỦ TRÌ (chiếu lên màn hình, có nút BẮT ĐẦU). Giữ riêng cho bạn:

Link NGƯỜI CHƠI (gửi cho người nghe):

Hai link này đã chứa sẵn cấu hình, bạn không cần sửa config.js. Muốn bắt đầu ván mới sạch điểm, đổi tên phòng ở Bước 2 rồi bấm kiểm tra lại để lấy link mới.
